# Library Management System

## Project Idea

This is a simple Python console program for managing a small library.

It manages books, members, borrowing, returning, searching, and overdue fines.

## Features

- Add books.
- Register members.
- Search for books.
- Borrow books.
- Return books.
- Calculate overdue fines.
- Show a member's borrowed books.
- Show available books.
- Show borrowed books.
- A member cannot borrow more than 3 books.

## How to Run

1. Make sure Python is installed.
2. Open the Python file.
3. Run the program.
4. Choose an option from the menu.
